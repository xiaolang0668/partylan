## Usage

1. 下载PartyLan [Steam](https://store.steampowered.com/app/1122990/PartyLAN).
2. 运行 PartyLAN.
3. 确保所有玩家都安装了PartyLan并运行. PartyLAN icon <img src="resources/common/images/icon.png" width="16" height="16" /> 应该在系统托盘中可见.
4. 对于主机，打开游戏并像往常一样作为局域网游戏主机启动.
5. 对于客户，单击系统托盘图标 <img src="resources/common/images/icon.png" width="16" height="16" />, 在“在线好友”菜单中选择主机，应将IP地址复制到剪贴板。
6. 对于客户端，打开游戏并使用剪贴板中的IP地址连接到主机.
